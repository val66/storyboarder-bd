Storyboard BD — installeur Windows
==========================================

Mon environnement d'exécution (sandbox Linux) est indisponible en ce moment,
donc je n'ai pas pu lancer le build moi-même. Le projet Electron est prêt
dans ce dossier ; il vous suffit de lancer 2 commandes.

Prérequis : Node.js installé (https://nodejs.org, version LTS).

Étapes (PowerShell ou Invite de commandes, dans ce dossier) :

1. npm install
2. npm run dist

Résultat : un installeur .exe apparaît dans le dossier "dist"
(ex. "Storyboard BD Setup 1.0.0.exe"). Double-cliquez dessus pour
installer l'application sur Windows 11 — raccourcis Bureau et Menu Démarrer
créés automatiquement.

Pour tester sans installer : npm start (lance l'app directement).

Fichiers du projet :
- index.html  → l'application (identique à celle du chat)
- main.js     → fenêtre Electron
- package.json → config du build (electron-builder, cible NSIS Windows)
